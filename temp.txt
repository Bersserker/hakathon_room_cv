# Система распознавания типа комнаты по изображению

## О проекте

**Авито** — самая посещаемая платформа объявлений в мире согласно данным SimilarWeb. Сегодня на Авито можно разместить объявления в категориях: Товары, Авто, Работа, Услуги, Недвижимость.

Для удобного и безопасного заключения сделок в сервис интегрирована **Авито Доставка**. Каждая пятая сделка на платформе совершается с Доставкой.

**Статистика Авито:**

* **230+ млн** активных объявлений.
* **72+ млн** пользователей ежемесячно.
* **10+ сделок** совершается каждую секунду.
* **12 000+** сотрудников.

---

## Цели и задачи

**Задача:** «Определение типа комнаты».

Необходимо решить задачу классификации изображений: обучить модель, которая по изображению определяет тип комнаты. Требуется предсказать один из 19 классов.

### Список классов

| ID | Название класса | ID | Название класса |
| --- | --- | --- | --- |
| **0** | Кухня / столовая | **10** | Коридор / прихожая |
| **1** | Кухня-гостиная | **11** | Гардеробная / кладовая / постирочная |
| **2** | Универсальная комната | **12** | Балкон / лоджия |
| **3** | Гостиная | **13** | Вид из окна / с балкона |
| **4** | Спальня | **14** | Дом снаружи / двор |
| **5** | Кабинет | **15** | Подъезд / лестничная площадка |
| **6** | Детская | **16** | Другое |
| **7** | Ванная комната | **17** | Предметы интерьера / бытовая техника |
| **8** | Туалет | **18** | Комната без мебели |
| **9** | Совмещенный санузел |  |  |

## Оценивание и формат данных

### Метрика

Используется **Macro F1-score**: считается F1 для каждого класса, затем берется невзвешенное среднее.

Пример расчета в `sklearn`:

```python
from sklearn.metrics import f1_score
f1_score(y_true, y_pred, average='macro')

```

### Формат submission-файла

Файл должен содержать заголовок и две колонки: `image_id_ext` и `Predicted` (целое число 0–18).

```csv
image_id_ext,Predicted
12345,11
12346,7

```

## Данные

### Основные файлы

* `train_df.csv` — обучающая выборка (размечена на Толоке).
* `val_df.csv` — данные для валидации.
* `test_df.csv` — тестовая выборка.
* `sample_submission.csv` — пример файла предсказаний.

### Структура датасетов

**Train / Val:**

* `item_id` — ID объявления.
* `image` — ссылка на изображение.
* `image_id_ext` — ID изображения.
* `result` — ID класса.
* `label` — название класса.
* `ratio` — доля толокеров, выбравших данный ответ.

**Test:** Содержит технические поля выходов модели *Avito Perform* (`microcat_name`, `microcat_prob` и др.) для использования в качестве фичей.

### Дополнительные признаки (Эвристики)

Доступны дополнительные данные для классов «кабинет», «детская», «гардеробная» в файлах `heuristics_*.csv`. Также предоставлены результаты детекторов:

* **Smart-crop:** координаты и площадь кропа.
* **Text detector:** количество текстовых областей.
* **Face detector:** наличие людей на фото.
